# React + Vite

Todo App
A React-based Todo App built as a second-semester project at AltSchool Africa. This app demonstrates core front-end development skills, including React, CSS, and HTML, with a focus on functionality, accessibility, and design.

FEATURES
CRUD Operations: Add, edit, delete, and view todos.
Pagination: Easily navigate through a large list of todos.
Nested Routes: View detailed information for each todo.
Search & Filter: Find todos by keywords or filter by status.
Local Storage: Persist todos across sessions.
Responsive UI: Optimized for various screen sizes.
Accessibility: Includes ARIA roles and other accessibility features.

USAGE
Navigate to / to view the todo list.
Add new todos using the input form.
Click a todo to view details (nested route).
Use the search and filter controls for quick access.
Pagination allows seamless navigation through multiple pages.

TECHNOLOGIES USED:
React.js
CSS
HTML
Axios for API requests
